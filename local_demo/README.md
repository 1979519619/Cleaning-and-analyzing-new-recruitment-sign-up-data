# 本地演示数据

`模拟招新报名数据_40人.csv` 是完全合成的 UTF-8 BOM CSV，共 40 条学生记录，不包含真实个人信息，用于快速体验完整处理流程。

数据覆盖的场景：

- 正常记录与前导零学号；
- 姓名、邮箱、第一志愿空值；
- 非纯数字学号；
- 邮箱与学号不匹配；
- 重复学号；
- 完全重复行；
- 单志愿与双志愿统计。

## 运行演示

在本仓库根目录执行：

```powershell
python main.py ".\local_demo\模拟招新报名数据_40人.csv" --output-dir ".\local_demo\output"
```

演示输出写入 `local_demo\output`，该目录已被 `.gitignore` 排除，不会入库。
