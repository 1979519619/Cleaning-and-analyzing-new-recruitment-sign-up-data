# Cleaning and analyzing new recruitment sign up data

项目开发部 2026 招新试题：使用 Python 标准库读取招新报名 CSV，完成数据概览、校验清洗、志愿统计和结果导出。

## 当前状态

三项需求均已实现并由自动化测试覆盖。每项需求通过独立 PR 开发，最终状态以 `main` 分支和 GitHub Actions 为准。

## 运行方式

```powershell
python main.py input.csv --output-dir output
python -m unittest discover -s tests -v
```

支持 Python 3.10 及以上版本，运行时只使用 Python 标准库。

程序成功处理后会在指定目录生成 `问题清单.csv`、`第一志愿汇总.csv` 和 `干净数据.csv`。

## 数据约定

输入 CSV 字段为：`姓名`、`学号`、`邮箱`、`志愿1`、`志愿2`、`推荐人`。文件按 `utf-8-sig` 读取，学号始终按字符串处理并保留前导零。

姓名、学号、邮箱和志愿1为必填；志愿2和推荐人可以为空。允许存在额外列，干净数据会保持输入表头顺序。

处理规则：

- 学号去除首尾空白后必须全部为数字；不限制长度并保留前导零。
- 邮箱必须与 `学号@smbu.edu.cn` 匹配；允许域名大小写不同，但不会猜测或修复错误内容。
- 同一学号出现两次或更多次时，涉及的全部记录都进入问题清单。
- 同一行的多个问题会用中文分号合并报告。
- 列数不足或过多的行会保留来源行号与原始行内容。
- 原始 CSV 始终只读，不会被原地修改。

项目没有真实报名数据。仓库中的示例和测试数据全部为自行构造的合成数据，不得提交真实姓名、学号或邮箱。

## 输出文件

- `问题清单.csv`：原始行号、输入字段、问题原因和原始行内容。
- `第一志愿汇总.csv`：只使用干净记录，按第一志愿统计人数。
- `干净数据.csv`：排除全部问题记录并去除字段首尾空白后的结果。

三个文件都使用 `utf-8-sig`，可直接用常见中文表格软件打开。

## 退出码

- `0`：处理完成并成功生成结果。存在行级问题仍属于正常完成，因为问题已写入问题清单。
- `1`：文件、编码、表头、权限或读写发生致命错误。
- `2`：命令行参数错误。
